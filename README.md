# lekalo-registry-aifhub

Клиент AIFHub registry для [Lekalo](https://github.com/ichinya/lekalo): каталог совместимых пакетов и профилей, версии, checksums, происхождение, conformance- и Framework Lift evidence, install plan.

- Задача интеграции — [#1](https://github.com/ichinya/lekalo-registry-aifhub/issues/1) (бывшая ichinya/lekalo#108).
- Необязательная интеграция: запуск Lekalo и установленных адаптеров работает без доступности registry; после установки проект работает с зафиксированным набором локально.
- Общий план отделения — [ichinya/lekalo#241](https://github.com/ichinya/lekalo/issues/241).
